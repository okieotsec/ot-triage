Offline use

The tool works fully offline. Download the two files on another computer, copy them here, and use Import from files. They get the same checks as a download. Files are stored in your per-user data folder.

Scoring

Only these four values can be changed. The rule structure is fixed. Changed values show a Custom scoring badge and are recorded in summaries and exports.

CVSS High line
CVSS score where a vulnerability counts as High. Default 7.0, allowed 5.0 to 8.0.
CVSS Critical line
Where a vulnerability counts as Critical. Default 9.0, allowed 8.0 to 10.0, at least 0.5 above the High line.
EPSS percentile cutoff
Percentile at or above which exploitation counts as likely. Default 0.95, allowed 0.5 to 0.999.
Stale after (days)
Days before threat data is flagged as stale. Default 7, allowed 1 to 90.
Example error: CVSS Critical line must be at least 0.5 above the High line.

About

Vulnerability Prioritizer v0.3 (design mockup)

Rule-based Now / Next / Never triage. Works fully offline; the only network access is a threat-data update that you start yourself.

Low exposure means no routable path from IT or the internet, verified by testing, not assumed from a firewall's existence.

Where the categories come from

The Now / Next / Never categories come from Dragos' annual ICS/OT Cybersecurity Year in Review vulnerability analysis. Other OT practitioners use similar framing. This tool adapts the idea with its own scoring rules; its definitions are not Dragos' and are documented in the policy page.
