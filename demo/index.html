Answer six questions about one vulnerability on one asset and see whether it is NOW, NEXT or NEVER, and why. This page runs the same rules as the OT Triage application, in your browser.

This is a small demo. Everything stays on this page: nothing you enter is sent, stored or logged, and the page loads nothing from other sites. It uses the default settings and the answers you choose. The application also looks up CISA's KEV catalog and EPSS, reads scanner exports and ranks whole files. Do not make decisions from this page.

Vulnerability

A number from 0.0 to 10.0, to one decimal place.

Only used for a reminder about Low exposure. It never changes the answer.

Threat

None: no known exploitation. Public exploit: a public or likely exploit. Active: attackers are using it now (for example, it is in CISA's KEV catalog). The application fills this in from KEV and EPSS data.

Asset and environment

Asset criticality

Crown jewel: assets whose compromise would stop operations or endanger safety. Important: significant but not critical. Standard: everything else.

Network exposure

Low means no routable path from IT or the internet, verified by testing, not assumed from a firewall's existence. If you are unsure, choose Medium.

Remediation and mitigation

Patch status

Pending means the vendor supports the product and a fix is on the way. End of life means no fix will ever ship.

Compensating controls

Strong: segmentation, virtual patching or allow-listing that actually stops the attack. Partial: ACLs or monitoring only. Partial controls rank the item lower inside its bucket but never change the bucket.
